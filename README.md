# Portfolio · Luis Angulo Couso

Mi web personal: [luisangulo.tech](https://luisangulo.tech).

Hecha con [Astro](https://astro.build/) y [Tailwind CSS](https://tailwindcss.com/), desplegada en Vercel.

## Desarrollo local

```bash
npm install
npm run dev
```

Todo el contenido (experiencia, proyectos, formación, certificaciones...) se edita en `src/config.ts`.
